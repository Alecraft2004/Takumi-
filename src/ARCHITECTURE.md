# Arquitectura UI de Takumi

- `design/`: tokens visuales globales.
- `components/atoms/`: elementos base reutilizables (botón, tarjeta, estado).
- `components/molecules/`: composiciones pequeñas (cabecera de página).
- `components/organisms/`: bloques complejos y autónomos (menú lateral).
- `components/templates/`: estructura de pantalla compartida (layout autenticado).
- `pages/`: vistas de negocio que unen los componentes.
- `data/`: datos de demostración.
- `assets/`: recursos visuales.
